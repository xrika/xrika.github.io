About This Project

Following three short courses on Frontend Masters, I explored generative art through a series of JavaScript libraries (where Math meets visual chaos) and it completely changed how I think about code!

Before this, JavaScript to me was pure functional. GenArt made it expressive. Writing math-driven code that produces geometric shapes, isometric forms, and organic patterns was genuinely mind-bending (!!!) and deeply satisfying when it worked.

These weren't pretty by accident (although some are). Every output required understanding what the library was doing under the hood, which pushed me to engage with JavaScript at a level I hadn't before.

What I Practised

I explored JavaScript libraries I'd never knew about before. I learnt about its integration, systems coordination and geometry logic, canvas and WebGL rendering. Learning to read documentation independently to produce outputs beyond the course brief was difficult but rewarding.

This series was my first real proof that I enjoy the intersection of code and visual output.
